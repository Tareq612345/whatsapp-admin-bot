# WhatsApp Admin Studio v0.2.0-beta.3

This beta fixes the first-run WhatsApp connection remaining on **Starting** without showing a QR code.

## Fixed

- Isolates the hidden WhatsApp host from the visible Studio Electron debugging endpoint.
- Prevents `wwebjs-electron` from attaching to the wrong window.
- Removes a stale bot-host `DevToolsActivePort` before startup.
- Preserves the existing WhatsApp session, configuration, database, and logs across restarts and updates.
- Adds clearer sanitized diagnostics when the Windows signature inspection command fails.

## Included

- Guided in-app WhatsApp QR login and saved sessions.
- One-time Owner Claim setup without manually entering a phone number or LID.
- Administrator roles, command permissions, reply customization, logs, and Arabic/English OCR.

## Important

This is an early test release. The installer is not code-signed yet, so Windows SmartScreen may show **Windows protected your PC**. Verify the SHA-256 checksum published with the installer.
