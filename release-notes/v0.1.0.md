# WhatsApp Admin Studio v0.1.0

The first public Windows pre-release of WhatsApp Admin Studio.

## Highlights

- Windows NSIS installer with Desktop and Start Menu shortcuts.
- Guided WhatsApp QR login inside the application.
- Start, stop, restart, connection status, and live process logs.
- Windows auto-start option.
- Administrator management with Owner, Administrator, and Moderator roles.
- Per-administrator command grants and explicit command restrictions.
- Commands available to regular members.
- Custom command prefix, aliases, enable/disable controls, and reply overrides.
- Admin Dashboard and Student Gate access from one interface.
- Arabic and English student-card OCR.
- Tesseract SIMD-LSTM with non-SIMD LSTM fallback.
- Optional RapidOCR worker with automatic Tesseract fallback.
- SQLite records and Excel export.

## Reliability work

- Only one Studio instance and one WhatsApp bot host can run.
- Orphan bot processes from early beta builds are cleaned automatically.
- Start and Restart requests are serialized.
- Duplicate WhatsApp events are filtered by message ID and a sender/body/time fallback.
- Graceful shutdown includes dashboard servers, SQLite, reconnect timers, and the WhatsApp client.

## Validation

The Windows release workflow:

1. validates JavaScript syntax;
2. runs all automated tests;
3. builds the packaged Windows application;
4. verifies RapidOCR and both required Tesseract LSTM cores;
5. starts, stops, and restarts the packaged EXE twice;
6. builds the NSIS installer;
7. publishes the installer only after every step succeeds.

## Important notes

- This is an early pre-release for controlled testing.
- The installer is not code-signed, so Windows SmartScreen may show a warning.
- The first OCR operation may download Arabic and English language data and cache it locally.
- WhatsApp automation uses an unofficial WhatsApp Web client and is not affiliated with WhatsApp.
- The previous command-line edition remains available on the `classic-cli` branch.
