# WhatsApp Admin Studio v0.2.0-beta.1

This test pre-release adds the complete first-run WhatsApp and Owner setup flow. It is intended for controlled Windows testing before the stable `v0.2.0` release.

## New in this beta

- Guided WhatsApp QR login inside Admin Studio.
- Saved WhatsApp session reused after restarts and version updates.
- Empty administrator list on new installations—no seeded phone number or LID.
- Six-digit, ten-minute, single-use Owner claim command.
- Automatic phone and WhatsApp LID capture from the verified claim message.
- Privileged commands remain blocked until Owner setup succeeds.
- Connected WhatsApp account display without exposing internal LIDs.
- Safe **Disconnect and show new QR** action for changing accounts or repairing a rejected session.
- Upgrade migration removes the previously seeded placeholder Owner and requests a proper claim once.
- Restart serialization and message-event deduplication remain enabled.
- Arabic and English OCR remain included.

## Required first-run test

1. Install this beta and open Admin Studio.
2. Scan the WhatsApp QR code.
3. Copy the `!claim` command shown in Studio.
4. Send it from the intended Owner account in a group containing the bot.
5. Test `!ping` and `!status`.
6. Restart Studio and confirm that WhatsApp does not request another QR.
7. Confirm that the claimed Owner can still run commands.
8. Test one Arabic and one English OCR image.

## Upgrade notes

- Installing over `v0.1.0` keeps the WhatsApp session and local settings.
- The old seeded placeholder Owner is intentionally removed and must be claimed once.
- Using **Disconnect and show new QR** removes only WhatsApp authentication/cache; bot configuration and Student Gate data remain.

## Known limitations

- This is a beta and the real WhatsApp claim/upgrade flow requires human verification.
- The installer is not code-signed, so Windows SmartScreen may display a warning.
- Automatic application updates are not enabled yet.
