# WhatsApp Admin Bot — Student Gate v2

بوت محلي لإدارة جروبات واتساب، حماية معدل الرسائل، قوائم حظر متعددة، وقراءة صور كارنيهات الطلاب محليًا لقبول طلبات الانضمام المناسبة.

## التحديث والتشغيل

من مجلد المشروع شغّل `update-and-start.cmd`، أو استخدم:

```powershell
git pull --ff-only origin main
npm install
npm start
```

الجلسة الحالية محفوظة في `.wwebjs_auth` والإعدادات القديمة محفوظة في `config.json`؛ كلاهما محلي ولن يتأثر بـ `git pull`.

بعد التشغيل:

- لوحة الإدارة القديمة: `http://127.0.0.1:3000`
- لوحة التحقق الجديدة: `http://127.0.0.1:3001`

## إعداد التحقق من الكارنيه

1. فعّل **Approve new participants** يدويًا من إعدادات الجروب.
2. تأكد أن رقم البوت Admin في الجروب.
3. شغّل البوت وأرسل رسالة عادية في الجروب حتى يظهر في لوحة التحقق.
4. افتح `http://127.0.0.1:3001` واضغط **قاعدة جديدة**.
5. اختر الجروب واكتب الكلمات التي يجب ظهور إحداها في الكارنيه، كلمة أو عبارة في كل سطر.
6. ابدأ مع **Dry-run مفعّل** للاختبار بدون قبول فعلي.
7. الطالب يرسل صورة الكارنيه للبوت على الخاص، ثم يقدم طلب انضمام من رابط الجروب.
8. عند تطابق قاعدة واحدة ووجود طلب لنفس الرقم، يقبل البوت الطلب تلقائيًا بعد إيقاف Dry-run.
9. الصور المكررة، القراءة منخفضة الثقة، عدم التطابق، أو تعدد الجروبات تنتقل للمراجعة اليدوية.

## التخزين والخصوصية

- OCR يعمل محليًا بالعربية والإنجليزية باستخدام Tesseract.js.
- أول صورة قد تتطلب تنزيل بيانات اللغة وتخزينها في الكاش.
- قاعدة البيانات: `data/students.sqlite`.
- يمكن تصدير السجل إلى Excel من لوحة التحقق.
- لا يتم رفع الصور أو قاعدة البيانات إلى GitHub.
- الملفات التالية مستبعدة من Git: `.wwebjs_auth`, `.wwebjs_cache`, `config.json`, `verification-config.json`, `data/`.

## متطلبات التشغيل

- Node.js 22.13 أو أحدث؛ Node.js 24 موصى به.
- اتصال إنترنت لأول تثبيت ولتنزيل بيانات OCR في أول استخدام.

## أهم أوامر الإدارة القديمة

```text
!help
!status
!dry-run on|off
!rate-limit 25 60
!lock-duration 5
!add-blocked-group
!remove-blocked-group
!list-blocked-groups
!sync-blocked
!set-approval-group
!approval-on
!approval-off
!approval-mode blacklist|allowlist
!approve-pending
!reject-blocked
```

> لا تستخدم `npm audit fix --force`؛ قد يغيّر إصدار مكتبة واتساب المتوافق مع الإصلاح الحالي.
